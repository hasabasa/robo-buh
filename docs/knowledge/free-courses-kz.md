# Бесплатные и открытые курсы по бухгалтерии РК

Карта обучающих ресурсов: откуда брать темы для базы знаний робота и живые разборы
типовых ситуаций (для промптов Qwen/KazLLM и наполнения RAG). Найдено 18.08.2026.

## Бесплатное

| Ресурс | Что | Ценность для robo-buh |
|---|---|---|
| [TSnik — вебинары](https://tsnik.kz/training/) | бесплатные вебинары с сертификатом, смотреть в любое время | живые разборы ситуаций → кейсы для базы знаний и тест-сценарии |
| [ЦДБ — дистанционное обучение](https://cdb.kz/distancionnoe-obuchenie/) | видеоуроки «с нуля» и для практиков | структура тем; часть бесплатна |

## Платное, но программы открыты

Даже у платных курсов **план уроков виден** — это готовая карта того, что должен «уметь»
робот (чему учат бухгалтера упрощёнки → что автоматизируем).

## Как применяем

- **Карта тем** платных программ → чек-лист сценариев, которые продукт должен закрывать.
- **Бесплатные вебинары** → корпус разборов типовых кейсов (нулёвка, ГПХ, освобождение,
  работники-иностранцы) для RAG и few-shot промптов классификатора.
- **Открытые статьи** (mybuh, ЦДБ) → уже частично вошли в глоссарий; при расширении базы
  знаний берём оттуда построчные примеры расчёта для тестовых сверок движка.

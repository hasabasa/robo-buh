# Официальный машинный шаблон формы 910.00 (СОНО)

`form_910_00_v27_r133.tar.bz2` — официальный шаблон КГД для 910.00, опубликован **30.12.2025**.

- **Источник:** `https://kgd.gov.kz/sites/default/files/ftpdata/SONO/install/forms/910.00/20251230/form_910_00_v27_r133.tar.bz2`
- **Индекс всех форм на 2026:** `https://kgd.gov.kz/ru/content/fno-na-2026-god-1`
- version=27, revisionNumber=133, code=910.00, **startDate=01.01.2023, endDate=31.12.2026**, charge=true, vat=false

## ⚠️ Распаковка

КГД отдаёт `.tar.bz2` с **обрезанной сигнатурой `BZ`** (файл начинается с `h1AY&SY`).
Перед распаковкой дописать байты `BZ`:

```bash
printf 'BZ' | cat - form_910_00_v27_r133.tar.bz2 > fixed.tar.bz2   # если качали заново
tar -xjf form_910_00_v27_r133.tar.bz2                              # этот файл УЖЕ с BZ
```

Внутри 4 файла: `*.xml` (структура, 140 полей `field_910_00_NNN`), `*_chr.xml` (карта
поле→КБК), `*_loc.xml` (RU-локализация + тексты формул/ФЛК), `*_packInfo.xml`.

## ⚠️ Критично: это СТАРЫЙ режим (3%), не НК-2026

Формула в шаблоне буквально: **`910.00.005 = 910.00.001 × 3%`**, есть соцналог (½ ИПН /
½ соцналог). Это режим до НК-2026. Версия под новый кодекс (ИПН **4%**, соцналог отменён)
на момент 30.12.2025 **не опубликована**.

Поэтому `backend/app/tax/xml_910.py` **НЕ привязан** к `field_910_00_NNN` этого шаблона —
он держит верную для 2026 логику (4%, без соцналога) с провизорной обёрткой. К каноничным
именам полей привяжемся, когда КГД выпустит шаблон 910.00 под НК-2026 (следить за индексом
выше) и/или после WSDL/XSD из Smart Bridge.

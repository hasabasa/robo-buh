# База знаний robo-buh

Рабочий справочник предметной области для разработчиков и ИИ-агентов проекта: единый
язык терминов + KZ-специфика с числами 2026 + привязка каждого термина к таблице/модулю/форме
продукта. Собрано многоагентным проходом 18.08.2026, сверено по открытым источникам (mybuh.kz,
pro1c.kz, uchet.kz, КГД, tengrinews); факты за пейволом ЦДБ помечены.

## Как это используется

1. **Единый словарь** — разработчики и ИИ-агенты берут термины отсюда, не изобретая свои.
2. **RAG-база** — эти файлы + НК 214-VIII + таблица КНП индексируются через **Embedder +
   Reranker + Milvus** (грант Астана Хаб, см. память `alem-ai-arsenal`) → чат «спроси
   бухгалтера» и подсказки классификатору операций.
3. **Сверка констант** — числа отсюда сверяются с `backend/app/taxconfig/kz_2026.py`;
   расхождения закрываются по первоисточнику (текст НК / официальные правила ФНО).

> ⚠️ Глоссарий — ориентир, не первоисточник. Перед зашивкой числа в расчётный движок
> (особенно ставки/пороги/вычеты 200.00) сверяем с текстом НК и официальным XSD/ФЛК.
